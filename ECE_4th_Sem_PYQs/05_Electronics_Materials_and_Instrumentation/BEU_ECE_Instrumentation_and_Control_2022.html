  1. Consider a system with controller \( G_c \), reference input \( R \), and disturbance input \( D \) acting on the plant \( \frac{1}{s(s+2)} \). If \( G_c \) is a proportional controller, \( G_c = K_p \), what value of \( K_p \) will cause the steady-state error for a unit ramp reference input to be 0.1?

    (a) If \( G_c \) is a proportional controller, \( G_c = K_p \), what value of \( K_p \) will cause the steady-state error for a unit ramp reference input to be 0.1?
